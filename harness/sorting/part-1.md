## Contradictions found

- **Line 251 is out of date.** It says `body` renders emphasis "as `<i>` tags". The code also writes `<b>`, `<sc>` and tags inside a word (`withMarkup(text, emphasis, strong, smallCaps, parts)`, scripts/drive.mjs:355, src/core/transcribe/markup.ts:487). Corrected in the row's Text.
- **Lines 18–19 against line 201 (an internal mismatch, not a code error).** "Runs a vision-grounded model pass" and "No API" are both true: the wizard still calls the API (src/core/transcribe/client.ts:11), and sessions do not. The product line now says both.
- **Line 172 is partly stale.** "The audit cannot see flatness": the audit now reports `flatStretches`, three or more sentences in one length band (scripts/voice.mjs:262). It still cannot judge dryness of content, so the rule stands, narrowed.
- **Lines 145–167 list fewer audit kinds than the code has.** `BiasKind` also has `direction`, `rhythm` and `person` (audit.ts:288). The list is incomplete, not wrong.
- **A trap, not a contradiction.** Line 180 says read the card with `scripts/voice.mjs`. The shelf's `voice/` folder holds two cards (`editor.json`, an empty 244-byte default, and `etsu-t-dhent.json`). So `voice.mjs card` with no `--name` throws "2 editors on this shelf" (voice.mjs:91–105). Either pass `--name` or remove the empty `editor.json`.
